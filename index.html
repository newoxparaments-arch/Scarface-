// Segurança Operacional //

Guia OPSEC

Protocolos e boas práticas para manter anonimato e segurança operacional em ambientes digitais adversos.

01
IDENTIDADE DIGITAL
Nunca utilize sua identidade real em operações sensíveis.
  • Separe contas pessoais de operacionais
  • Use emails descartáveis e temporários
  • Nunca reutilize usernames entre plataformas
  • Personas separadas para cada contexto
  • Cuidado com metadados em arquivos enviados
02
ANONIMIZAÇÃO DE REDE
Seu IP é sua identidade — proteja-o em todos os momentos.
  • Sempre utilize VPN confiável de no-log
  • Tor Browser para operações críticas
  • Evite WebRTC leaks em navegadores
  • DNS over HTTPS para consultas seguras
  • Nunca acesse contas pessoais via Tor op.
03
COMUNICAÇÃO SEGURA
Assuma sempre que qualquer canal pode estar comprometido.
  • Use comunicação E2E (Signal, Session)
  • Evite Discord para assuntos sensíveis
  • Mensagens autodestrutivas quando possível
  • Nunca compartilhe localização real
  • Verifique fingerprints de contatos
04
DISPOSITIVOS & HARDWARE
Seu dispositivo é a primeira linha de defesa e ataque.
  • Use SOs focados em privacidade
  • Whonix ou Tails para operações críticas
  • Câmera e microfone cobertos quando não usados
  • Full disk encryption obrigatória
  • Evite dispositivos de segunda mão sem formatação
05
COLETA DE OSINT
Seja invisível enquanto coleta informações sobre alvos.
  • Nunca acesse perfil do alvo logado
  • Use conta limpa ou modo anônimo
  • Salve cópias (screenshots + archive.ph)
  • Correlacione dados de múltiplas fontes
  • Documente timestamps e fontes de cada dado
06
CONTRAINTELIGÊNCIA
Proteja operações de infiltradores e agentes adversos.
  • Compartimentalize informações por necessidade
  • Nunca discuta operações em canais abertos
  • Verifique identidade de novos membros
  • Use honeypots para detectar vazamentos
  • Plano de contingência para comprometimentos
